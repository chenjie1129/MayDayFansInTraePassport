# Bubu carrot reference

Source: https://github.com/chenjie1129/MayDayFansInCodex

`bubu_reference_idle.png` is derived from row 0, frame 0 of the source
`bubu-carrot/spritesheet.webp`. It is used as the visual reference for the
32x32 tribe icon and the six 48x48 pet forms generated in this directory.
