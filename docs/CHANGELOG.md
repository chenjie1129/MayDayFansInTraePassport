# Changelog

## Unreleased

- Hardened the `Places` demo against false "new place" detection while the device never moves: real-device logs showed same-location Jaccard scores oscillating between 600‰ and 1000‰ because one or two borderline BSSIDs drift in and out of the top-8 fingerprint, and a single scan below the 50% threshold immediately created a duplicate place. Fingerprints now keep the 12 strongest BSSIDs; similarity uses the overlap coefficient (intersection / min(|A|,|B|)) so extra weak APs seen in one scan no longer drag the score down; and a hysteresis state machine (`place_fp_observe`, pure logic in `main/place_fp.c`) treats 350–499‰ as a grey zone that never creates a place and schedules a 4 s quick rescan, while scores below 350‰ require two consecutive confirmations before a new place is committed (an empty library still creates the first place immediately). The page shows `CHECKING...` / `WEAK n% - RESCAN SOON` while confirming. The NVS blob version is bumped to 2 (1,416 bytes; legacy v1 8-BSSID blobs are detected and safely reset instead of mis-parsed), and host unit tests now cover overlap math, threshold boundaries, the exact V0.1 false-positive regression (5/8 shared = Jaccard 454‰ vs overlap 625‰), and every hysteresis transition.
- Added the `Places` demo ("Place Memory"): an offline place recognizer with no network or GPS. Every 60 seconds (or immediately on OK click) a one-shot active Wi-Fi scan takes the eight strongest BSSIDs as the current place fingerprint; the Wi-Fi stack is fully stopped and deinitialized after each scan via `bsp_wifi_scan_once()` in `components/bsp` (`WIFI_STORAGE_RAM`, default STA netif created and destroyed per cycle). Fingerprints match saved places by integer-only Jaccard similarity with an inclusive 50% overlap threshold; the matching logic is hardware-independent (`main/place_fp.c`) with host unit tests in `tests/test_place_fp.c` covering identical / partial-overlap / disjoint / exactly-50%-boundary cases, wired into the `tools/validate.sh` static gate. Up to 16 places (8 BSSIDs + name + visit count each, single ~1 KB NVS blob, namespace `placemem`) persist across power loss; new places flush immediately while visit-count flushes throttle to 5 minutes with one final flush on page exit. The single page shows KNOWN / NEW / UNKNOWN place status, fingerprint strength (average RSSI: STRONG / GOOD / WEAK / POOR), and the saved-place count; UP/DOWN browse saved places and long-press OK returns to the menu. All blocking scan/NVS work runs in a persistent queue-driven worker task, the place database is guarded by a mutex, and worker-to-UI updates take the LVGL lock briefly and no-op after the page is deleted.
- Reflowed the demo menu grid for ten entries: cards are now 38 px tall on a 45 px pitch with the mascot standing on the grass strip, so the fifth card row no longer overlaps the mascot.
- Fixed `tools/install-actionlint.sh` on macOS: the system BSD `sha256sum` lacks GNU `--check/--status`, so checksum verification now uses `shasum` on Darwin while Linux keeps GNU `sha256sum`.
- Added the `Answer` demo ("Answer Book"): focus on a question and press OK to flip the book; after a 1.3 s suspense animation (flashing `?`, dotted progress, synthesized whoosh) a random Chinese answer fades in with a three-note reveal chime. UP/DOWN switch three decks (Classic / Worker / Programmer, 16 answers each, sourced from `main/answers.json`), deck input is ignored during the flip, and consecutive draws never repeat. Chinese text renders through a 24 px bpp4 subset font (`main/answer_24.c`, 176 glyphs) generated by `tools/gen_answer_data.js` plus `lv_font_conv`, stored in flash with zero RAM cost; all PCM audio is synthesized at runtime and played by a persistent queue-driven worker task, with no NVS writes.
- Added the `WoodFish` demo ("electronic wooden fish"): tap OK to accrue merit, with rising critical-hit (+10) probability as the combo grows; UP switches three skins (classic wood / gold / purple) and DOWN cycles auto-tap rhythms (off / slow / mid / fast). Merit persists via batched NVS commits (every 20 taps or 5 seconds, plus a flush on exit); blocking audio, flash, and I2C work runs in a persistent queue-driven worker task; LVGL feedback uses zero-allocation background-color flashes instead of per-frame zoom transforms.
- Fixed the `Answer` demo showing a blank page on hardware: the CJK subset font was generated with lv_font_conv's default compressed bitmap format while `CONFIG_LV_USE_FONT_COMPRESSED` was disabled, so LVGL silently returned no bitmap for every Chinese glyph (book title, deck name, and answers were all invisible); `main/answer_24.c` is now regenerated with `--no-compress`. Also fixed the flip page's drop shadow: `ui_pixel_panel_create()` parents the shadow on the screen rather than on the panel, so hiding the page left the shadow on screen covering the closed-book cover; the page now builds its own transparent container with the shadow as a child, so hiding the container hides the shadow as well.
